# cybersecurity-task-2
Operating System Security Fundamentals

## Objective
The objective of this task is to understand operating system–level security concepts by exploring user accounts, permissions, services, and basic OS hardening techniques using Ubuntu Linux.

## Tools Used:
- Ubuntu Linux (Virtual Machine)
- Oracle VirtualBox
- Linux Terminal
- UFW Firewall

## Task Activities Performed:

### 1. User Accounts & Privileges:
- Checked current user using `whoami`
- Studied root vs normal user privileges
- Used `sudo` to perform administrative tasks

### 2. File Permissions & Ownership:
- Created files and directories
- Checked permissions using `ls -l`
- Modified permissions using `chmod`
- Changed ownership using `chown`
- Understood read, write, and execute permissions

### 3. Principle of Least Privilege:
- Understood why users should have limited access
- Practiced using admin rights only when required

### 4. Firewall Configuration:
- Checked firewall status using `ufw status`
- Enabled firewall using `ufw enable`
- Allowed basic rules when required

### 5. Process & Service Management:
- Viewed running processes using `ps` and `top`
- Listed active services using `systemctl`
- Disabled unnecessary services to reduce attack surface

## OS Hardening Practices Implemented:
- Firewall enabled
- Least privilege followed
- Unnecessary services disabled
- Secure user access maintained
- System kept updated

## Learning Outcome
Through this task, I gained practical understanding of operating system security, Linux permissions, service management, firewall configuration, and OS hardening concepts essential for cybersecurity roles.
